- Auth phase 3 (sign-in, register & sign-out UI): `pages.signIn`/`pages.error` in `src/auth.config.ts` point NextAuth's own redirects at `/sign-in`, and `SIGN_IN_PATH`/`DEFAULT_SIGN_IN_REDIRECT` live there so the proxy, the actions and the pages share one definition. `src/actions/auth.ts` holds the credentials, GitHub and sign-out actions; the credentials action rethrows anything that is not an `AuthError`, because a *successful* sign-in throws `NEXT_REDIRECT` and swallowing it would strand the user on the form.
